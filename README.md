## 核心内容

### 1. 四国用户画像（analysis/）
来华留学生用户画像分析（俄罗斯/泰国/马来西亚/孟加拉）：
- Google Trends + Yandex Wordstat 关键词研究
- 16 张数据可视化图表（性别/国别/内容偏好/CSR用户）
- **结论被公司国际部采纳**

### 2. 温馨日历（calendar/）
情侣场景化产品，已部署 GitHub Pages：
`https://zhangjianpeng66.github.io/warm-calendar/`

### 3. 命运途径游戏化设计（fate-pathway/）
基于"大事不虚、小事不拘"原则，为《诡秘之主》命运途径设计的完整游戏化方案：
- 9 序列技能体系（占卜家→诡秘侍者）
- 幸运值核心机制（主动承担厄运换取幸运）
- 神奇物品与扮演法设计

### 4. Hermes AI 助手（hermes/）
个人 AI 助手：记忆系统（RAG 最简实现）+ 人格配置 + 定时推送 + 企业微信接入。

### 5. 72 集《背着生命走长征》（script/）
红色题材长篇短剧，主笔创作，基于红25军真实史实。
